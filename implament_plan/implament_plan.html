Frontend (Puttra) · Whale · 2026-08-10

Filter chip → dropdown (Live Monitor / ผลการแข่งขัน) + Pagination (รายชื่อนักวิ่ง)

Gong สั่งผ่าน remote-control: form "Live Monitor" กับ "ผลการแข่งขัน" เปลี่ยน check ระยะ/เพศ/รุ่นอายุ จาก chip-button เป็น select dropdown, form "รายชื่อนักวิ่ง" เพิ่ม pagination

สภาพโค้ดปัจจุบัน

ChipGroup.jsx เป็น pill-button toggle ใช้ร่วมกันใน MonitorFilterBar.jsx + ResultsFilterBar.jsx ทั้ง 3 field (ระยะ/เพศ = single-select, รุ่นอายุ = multi-select ผ่าน prop multiSelect) ไม่มีที่อื่นใช้แล้ว

Filter state shape เดิม { category, gender, ageGroups: string[], query } ใน lib/results.js (matchesAgeGroups, resultsCsvFilename, activeFilters) — รอบนี้ไม่แตะ model, เปลี่ยนแค่ widget input

groupBy (Results) กับ category filter ใน RunnersPage.jsx ใช้ native <select class="search search--select"> อยู่แล้ว — เอา pattern นี้ไปใช้กับ ระยะ/เพศ

ไม่มี pagination component ในระบบเลย, ไม่มี component test (มีแต่ lib/hook test) — filter model ไม่เปลี่ยน test เดิมไม่พัง

Gong confirm แล้ว:

  • รุ่นอายุ ยังเลือกได้หลายรุ่นเหมือนเดิม (multi-select) แค่เปลี่ยน UI เป็น dropdown (checkbox list) ไม่ตัดเหลือ single-select
  • Pagination: 20 แถว/หน้า, แสดงเลขหน้า

สิ่งที่แก้

  1. ระยะ/เพศ → native <select> — ใน MonitorFilterBar.jsx + ResultsFilterBar.jsx แทน ChipGroup ด้วย <select className="search search--select"> เหมือน groupBy เดิม (<option value={ANY}>ทุกระยะ/ทุกเพศ</option> + map ตัวเลือก)
  2. รุ่นอายุ → MultiSelectDropdown.jsx (ใหม่) — trigger button style เดียวกับ .search--select โชว์ label สรุป (ทุกรุ่น / N รุ่น), คลิกเปิด glass-panel menu เป็น checkbox list ของ AGE_OPTIONS, ปิดเมื่อคลิกนอกกล่อง/กด Escape, ไม่มี dependency ใหม่ — props { id, legend, allLabel, options, value, onSelect } รับ/คืนค่าเป็น string[] เหมือน ChipGroup multiSelect เดิม (drop-in)
  3. ลบ ChipGroup.jsx — หลังไม่มีคนเรียกแล้ว ลบไฟล์ + CSS ที่กลายเป็น orphan (.filter-chip, .filter-bar__options) หลัง grep ยืนยันไม่มีที่อื่นใช้
  4. CSS ใหม่ใน results.css — .multiselect-dropdown + __trigger + __menu (glass panel, position:absolute) + __option (checkbox row), เพิ่มเข้า mobile breakpoint เดิมให้เต็มความกว้างจอเล็ก
  5. Pagination.jsx (ใหม่) — เลขหน้า + ปุ่ม prev/next, style เดียวกับ .btn/.filter-chip, หน้าปัจจุบัน = btn-accent. Props { page, totalPages, onChange }
  6. RunnersPage.jsx — PAGE_SIZE = 20, useState page, reset page=1 ตอน query/category เปลี่ยน (useEffect), slice rows เป็น pagedRows สำหรับ render table (empty-state เช็คจาก rows.length ไม่ใช่ pagedRows), export CSV ใช้ rows เต็มเหมือนเดิม (ไม่ตัดตามหน้า), render <Pagination> ใต้ table ตอน totalPages > 1
  7. CSS pagination — เพิ่ม .pagination block ใน dashboard.css ใกล้ .table-wrap

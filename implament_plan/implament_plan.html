Deploy division-backend (Go) ขึ้น Render — free tier, ไม่ต้องผูกบัตร

ลอง Fly.io แล้วชน "machine count exceeds organization limit" — org personal มี 0 apps/0 machines อยู่แล้วแต่ยังโดนบล็อก ยืนยันว่าเป็น billing จริง (Fly.io เลิก free-tier แล้ว) ไม่ใช่ชน quota เดิม

ทางเลือก "เขียนตรง Supabase, ตัด Go ออก" — ไม่แนะนำ:

ขัด division-backend/CLAUDE.md โดยตรง ("All writes go through the Go API... Frontend never writes to Supabase directly") validation จริง (duplicate-scan, status transition) อยู่ใน internal/scan เป็น transaction logic ไม่ใช่ DB constraint, RLS ตอนนี้ default-deny ทุกตารางยกเว้น live_progress — ย้ายไป Postgres function/RLS ทั้งชุดคืองาน rework ใหญ่ ไม่ใช่ deploy step

Gong เลือกแล้ว: Render free tier + Go backend เดิม ไม่แก้ logic ใดๆ

ขั้นตอน

  1. สร้าง render.yaml ที่ root repo — Blueprint: web service trail-running-api, env: docker, dockerfilePath: division-backend/Dockerfile, dockerContext: division-backend, region Singapore, plan free, healthCheckPath: /healthz, DATABASE_URL/SUPABASE_URL ตั้ง sync: false (ไม่เก็บ secret ในไฟล์)
  2. Commit + push render.yaml ขึ้น GitHub — จำเป็นเพราะ Render Blueprint อ่านจาก repo โดยตรง (จะขอ confirm แยกก่อน push จริง เพราะกระทบ remote repo)
  3. Gong ทำเองใน browser (ไม่มี Render API key ให้ผมทำแทน):
    • Render → New → Blueprint → เชื่อม GitHub repo hello-all-ai008/trail-running
    • กรอก DATABASE_URL, SUPABASE_URL ในฟอร์ม
    • กด Apply — Render build + deploy จาก Dockerfile
  4. Gong ส่ง URL ที่ได้กลับมา (รูปแบบ https://trail-running-api.onrender.com)
  5. ตรวจสุขภาพ — curl -i <render-url>/healthz ต้องได้ 200 (รอบแรกอาจช้าเพราะ cold start)
  6. ปิด loop กับ frontend — อัพเดท Vercel env VITE_API_BASE เป็น URL จริง แล้ว vercel --prod redeploy

ไฟล์ที่แตะ

ไฟล์เปลี่ยนอะไร
render.yamlใหม่ (root repo)

ไม่แตะ: โค้ด Go, fly.toml/Dockerfile เพิ่มเติม (พร้อมอยู่แล้ว เก็บไว้เผื่อย้ายกลับ Fly.io วันแข่งจริง)

ยังไม่ทำรอบนี้

  • Fly.io deploy จริง (รอ Gong ผูกบัตรทีหลัง ถ้าต้องการ always-on วันแข่งจริง)
  • แก้ doc เก่าใน division-backend/CLAUDE.md (region ผิด) — ไม่ใช่ blocker
  • ยืนยัน scan จริงแบบ end-to-end — รอ Gong สร้าง staff Supabase Auth account เอง

ความเสี่ยง

  • Cold start 20-50 วิหลัง idle 15 นาที — ไม่ใช่บั๊ก เป็นข้อจำกัด free tier (Gong รับทราบแล้ว)
  • ขั้นตอน 3 ต้อง Gong ทำเองผ่าน browser ทั้งหมด
  • push render.yaml ขึ้น GitHub — ขอ confirm แยกก่อนรัน git push

การตรวจสอบ

  1. curl -i <render-url>/healthz → 200
  2. เปิด https://trail-running.vercel.app หลัง redeploy frontend เช็ค network reachable

รอ Gong พิมพ์ "ลุยได้" ก่อนเริ่ม execute — จะไม่เริ่มสร้างไฟล์/commit/push จนกว่าจะได้รับคำสั่งชัดเจนอีกที

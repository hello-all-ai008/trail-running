แถว "ประเภทการแข่งขัน" — responsive สวยขึ้น + ปุ่มลบเป็นไอคอน

Gong ส่งภาพมาชี้ — แถว radio + ช่องกรอกระยะทาง + "กม." + จำนวนคน + ปุ่มลบ ถูกยัดรวมกันเป็นเส้นเดียวในพาเนลแคบ (280-360px) ดูอัดแน่น แถมปุ่มลบยังเป็นตัวอักษร "×" สีแดงเฉยๆ ไม่ใช่ไอคอนที่ตั้งใจออกแบบ — งานนี้คือแก้ CSS/JSX ล้วนๆ ไม่แตะ state หรือ logic ใดๆ

ระยะทาง+"กม." รวมเป็นกล่อง pill เดียวแทนที่จะเป็นสองก้อนหลวมๆ, จำนวนคนเป็น badge พื้นเทาอ่อน, ปุ่มลบเป็นวงกลมพื้นแดงจางๆ + ไอคอนถังขยะ (สไตล์เดียวกับไอคอนใน Sidebar.jsx's ICONS — feather-style, stroke="currentColor") แทนตัวอักษร ×

Responsive: กลุ่ม radio+ระยะทาง กับกลุ่มจำนวนคน+ปุ่มลบ แยกเป็นสอง flex group ในแถวเดียวกัน (`justify-content: space-between`) ถ้าพาเนลแคบเกินจะรวมกันพอดี ตัว flex-wrap จะให้กลุ่มหลังตกไปบรรทัดใหม่เองอัตโนมัติ ไม่ต้องเขียน media query

การตรวจ

  1. เปิดหน้า "สร้าง BIB (PDF)" เช็คแถวที่ความกว้างพาเนล ~280px และ ~360px (ตาม minmax(280px, 360px)) และตอนจอแคบ <1024px ที่พาเนลเต็มความกว้าง — แถวไม่ล้น ไม่บีบข้อความจนอ่านไม่ออก
  2. ปุ่มลบเป็นไอคอนถังขยะ มี hover state (วงกลมแดงจางเข้มขึ้น) กดแล้วยังลบแถวได้ถูกต้องเหมือนเดิม
  3. แถวที่เลือกไว้ (radio checked) เห็นพื้นหลังจางๆ เพิ่มจากเดิม ไม่ใช่แค่กรอบสีเปลี่ยน

ดูแล้วโอเคบอก "ลุยได้" — ยังไม่ได้แตะโค้ด รอ Gong ตรวจก่อน

ค้นหานักวิ่ง + การ์ด Overall Top 3 + กติกาตัดสิทธิ์รางวัลรุ่น

เพิ่ม 2 อย่างจากที่ Gong ขอ: (1) ช่องค้นหาชื่อ/BIB บนทั้ง 2 หน้า (2) การ์ดใหม่ใน Live Monitor โชว์ผู้ชนะ overall อันดับ 1-3 ของแต่ละระยะ (รวมทุกเพศทุกวัย) พร้อมกติกา — คนที่ติด overall แล้ว ไม่มีสิทธิ์ในรางวัลรุ่นย่อยของระยะนั้นอีก และจะไม่โผล่ในการ์ดรุ่นย่อยเลย

ยังไม่ได้ลงมือ — รอตรวจไฟล์นี้ก่อน โดยเฉพาะจุดที่ผมตัดสินใจเองแทน (ทำเครื่องหมายไว้ชัดด้านล่าง)

ที่ Gong ยืนยันแล้ว

ช่องค้นหาทั้ง Live Monitor และผลการแข่งขัน
กติกาตัดสิทธิ์มีผลเฉพาะการ์ด Live Monitor ใหม่ — หน้าผลการแข่งขัน/e-Slip อันดับรุ่นยังนับทุกคนเหมือนเดิม ไม่กระทบ
เมื่อตัดคนติด overall ออกเติมคนถัดไปขึ้นมาแทนจนครบ 5 (renumber ใหม่ 1-5 เฉพาะคนที่ยังมีสิทธิ์)

จุดที่ผมตัดสินใจเอง — อยากให้ตรวจเป็นพิเศษ

การ์ด Overall Top 3 กรองด้วย "ระยะ" (chip MKT33/MKT50) อย่างเดียว — ตัวกรอง เพศ / รุ่นอายุ / ค้นหา จะไม่มีผลกับการ์ดนี้

เหตุผล: "Overall รวมทุกเพศทุกวัย" ตามนิยามคือข้ามมิติเพศ/อายุอยู่แล้ว ถ้าไปกรองด้วยเพศ/อายุจะขัดกับความหมายของการ์ด แต่ระยะ (MKT33/MKT50) ยังกรองได้ตามปกติ (เลือกดูเฉพาะ MKT50 การ์ด MKT33 overall จะหายไป)
ถ้า Gong อยากให้กรองอย่างอื่นได้ด้วย บอกได้เลย แก้ไม่ยาก

รายละเอียด

1. ช่องค้นหา

ใช้ตรรกะเดียวกับช่องค้นหาที่มีอยู่แล้วในหน้า "รายชื่อนักวิ่ง" (RunnersPage.jsx) — ค้นจาก BIB หรือชื่อ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) แต่ต่างจากที่นั่นตรงที่ตรงนี้ผูกเข้ากับตัวกรองรวม (results.js) ไม่ใช่กรองทีหลังฝั่งหน้าจอ — ไม่งั้น badge จำนวนคนต่อรุ่น/การซ่อนการ์ดว่างจะไม่อัพเดทตาม 

// results.js
EMPTY_FILTER: { category: ANY, gender: ANY, ageGroups: [], query: '' }
filterFinishers: + query predicate (bib.includes(q) || name.toLowerCase().includes(q))
describeFilter: + {key:'query', label: `ค้นหา "..."`}  เมื่อพิมพ์อะไรไว้
resultsCsvFilename: ไม่เอา query ไปใส่ชื่อไฟล์ (free text ไม่เหมาะเป็นชื่อไฟล์)

วางเป็นช่อง <input className="search"> อยู่หน้าสุดของแถบตัวกรอง ทั้งสองหน้า

2. การ์ด Overall Top 3 + กติกาตัดสิทธิ์

rankCategory ที่มีอยู่แล้ว (อันดับภายในระยะ ไม่แยกเพศ/วัย) คือ "อันดับ overall ของระยะนั้น" พอดี ไม่ต้องคิดสูตรใหม่ — คนที่ rankCategory <= 3 คือคนที่ติด overall

  • คนติด overall: โผล่ในการ์ด Overall Top 3 ของระยะนั้น, หายไปจากการ์ดรุ่นย่อยทั้งหมด
  • คนที่เหลือในรุ่นย่อย: เรียงลำดับใหม่ 1..N เฉพาะคนที่ยังมีสิทธิ์ (เวลาวิ่งเดิม แค่เลขอันดับขยับปิดช่องว่าง) เรียกเลขนี้ว่า awardRank — คนละตัวกับ rankAge เดิมที่หน้าผลการแข่งขัน/e-Slip ยังใช้อยู่ ไม่แตะ
  • badge "จบ N คน" ยังนับรวมคนติด overall เหมือนเดิม (ขนาดสนามจริง) — มีบรรทัดเสริมสีแดง "ตัดสิทธิ์ N คน (ติด Overall)" เมื่อมีคนโดนตัดสิทธิ์ กันงงตัวเลขไม่ตรงกัน
  • เคสรุ่นเล็กที่คนติด overall หมดรุ่น (เหลือ 0 คนมีสิทธิ์): การ์ดยังโชว์อยู่ (รุ่นนี้มีคนจบจริง) แต่ขึ้นข้อความแทนตาราง "ผู้เข้าเส้นชัยทั้งหมดติด Overall — ไม่มีผู้มีสิทธิ์รับรางวัลรุ่นนี้"
  • โหมด "สแกนล่าสุด" ไม่มีแนวคิด overall — การ์ดนี้โชว์เฉพาะโหมด "อันดับ 1-5"

ความเสี่ยง

1. ตอนนี้มีเลขอันดับ 2 ชุดที่ไม่เท่ากันได้บนคนเดียวกัน (rankAge หน้าผล vs awardRank Monitor) — เป็นไปตามที่ตกลง แต่ต้องมี comment กันคนมาสับสนว่าทำไมเลขไม่ตรงกัน
2. การ renumber ต้องไม่แตะ ranks ที่ใช้ร่วมกัน — เป็น partition+reindex เฉพาะใน monitor.js เท่านั้น
3. ตัวกรองของการ์ด Overall (ระยะอย่างเดียว) เป็นการตัดสินใจของผม ไม่ใช่สิ่งที่ Gong ยืนยันตรง ๆ — จุดที่มีโอกาสโดนแก้มากสุด

การตรวจ

cd division-frontend
npm test && npm run lint && npm run build
  1. ค้นหา BIB/ชื่อ ทั้งสองหน้า → เห็นเฉพาะคนที่ตรง การ์ด/แถวที่ไม่ตรงหายไป
  2. Live Monitor เห็นการ์ด Overall Top 3 แยก MKT33/MKT50 คนละ 3 คน
  3. คนที่ติด overall หายจากการ์ดรุ่นย่อยของตัวเอง อันดับ 1-5 ที่เหลือเรียงใหม่ไม่มีช่องว่าง
  4. badge "จบ N คน" ไม่เปลี่ยน + มีบรรทัด "ตัดสิทธิ์ N คน" โผล่เมื่อมีคนถูกตัด
  5. หน้าผลการแข่งขัน/e-Slip อันดับรุ่นยังนับทุกคนเหมือนเดิม ไม่เปลี่ยน
  6. สลับไปโหมด "สแกนล่าสุด" → การ์ด Overall หายไป (โชว์เฉพาะโหมดอันดับ)

ดูแล้วโอเคบอก "ลุยได้" โดยเฉพาะช่วยยืนยันจุดตัวกรอง Overall card ด้านบนก่อน ไม่งั้นบอกจุดที่อยากแก้ได้เลย

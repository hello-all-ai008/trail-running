แก้ category/checkpoint เก่า (MKT33/MKT50, A1/A2/A3) ที่ hardcode ไว้ในโค้ด

Deploy Vercel รอบก่อนสำเร็จแล้ว — เช็คผ่าน browser พบว่า Dashboard ขึ้น "ผู้สมัครทั้งหมด 1003" ถูกแล้ว (live data จริง) แต่ "Progress by Category" ยังขึ้น MKT33/MKT50 และ "Runner Flow" ยังขึ้น A1/A2/A3 — ของ event เก่า

สาเหตุ

division-frontend/src/lib/raceData.js hardcode ค่า 2 ตัว ไว้ตั้งแต่ยุค mock เดี่ยว event เก่า: 

export const CATEGORIES = ['MKT33', 'MKT50']
export const CHECKPOINTS = [
  { id: 'A1', name: 'A1 Mae Kha Nin' },
  { id: 'A2', name: 'A2 Doi Pha Daeng' },
  { id: 'A3', name: 'A3 Huai Nam Sai' },
]

ถูก import ตรงๆ (ไม่ derive จากข้อมูลจริง) ใน 9 ไฟล์ — จำนวน runner รวมดึงจาก runners จริงถูกแล้ว แต่ตัวกรอง/กลุ่ม/ป้าย category กับ checkpoint ยังอ่านค่า static เดิมอยู่

ข่าวดี — มี pattern แก้ถูกอยู่แล้วในโค้ด: lib/results.js:110-119 (computeRanks) derive category จากข้อมูลจริงถูกวิธีอยู่แล้ว ([...new Set(finished.map(r => r.category))]) ใช้ CATEGORIES แค่เป็น sort hint เท่านั้น — แผนนี้เอา pattern เดียวกันไปใช้ที่เหลือ

Gong confirm แล้ว:

  • Checkpoint: Baanpong 2026 ยังไม่มีข้อมูลจริงใน DB เลย (flag ไว้ตั้งแต่รอบก่อน) และยังไม่มีรายชื่อพร้อม → รอก่อน — Runner Flow โชว์แค่ START/FINISH ไปก่อน ไม่โชว์ A1/A2/A3 ปลอมๆ
  • /register ยังเปิดรับสมัครจริงอยู่ → อัพเดทเป็น BP10/BP5 ด้วย

สิ่งที่แก้

  1. raceData.js — เพิ่ม categoriesFromRunners(runners) (pattern เดียวกับ results.js), เปลี่ยนชื่อ CATEGORIES → REGISTRATION_CATEGORIES ค่าเป็น ['BP10','BP5'] (ใช้เฉพาะหน้า /register ที่ไม่มี live data ให้ derive เพราะ race_categories ไม่มี RLS anon-read), CHECKPOINTS → []
  2. หน้า staff (Dashboard/Runners/Monitor/Results filter) — เปลี่ยนจาก CATEGORIES.map() เป็น categoriesFromRunners(runners).map() ทุกจุด (มี runners เป็น prop อยู่แล้วทุกที่)
  3. StationPage.jsx — กัน crash: CHECKPOINTS[0].id → CHECKPOINTS[0]?.id ?? '', เพิ่ม empty state "ยังไม่มีการตั้งค่า Check Point" ตอนไม่มี checkpoint
  4. Runner Flow / ESlipModal / raceEngine (mock) — ไม่ต้องแก้ ของเดิม guard ด้วย .map/.filter/.some ทำงานถูกอยู่แล้วกับ array ว่าง (Runner Flow จะเหลือแค่ START/FINISH เอง)
  5. RegisterHero.jsx — เปลี่ยน category card เป็น BP10 (10 กม. · Hard Rock) / BP5 (5 กม. · Soft Rock) จากข้อมูลจริงใน race_categories, ตัด "ระยะสะสมความสูง" ออกเพราะไม่มีตัวเลขจริง (ไม่ใส่เลขมั่ว)
  6. RegisterForm.jsx — เปลี่ยน import ตามชื่อใหม่ ที่เหลือ logic เดิม

Flag ไว้ ไม่แก้รอบนี้ — ต้องรอ copy จริงจาก Gong

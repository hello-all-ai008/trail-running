Pagination — เลขติด prev + เรียงลำดับคงที่ 1 2 3 4 … N

ต่อจาก pagination 2 รอบก่อน (เพิ่ม pagination → เต็มความกว้าง + prev/next ชิดขอบ, commit 14b8715) — รอบนี้ Gong ขอเพิ่ม 2 อย่างพร้อมกัน (ยังไม่ได้ลงโค้ดสักอันเลย รวมเป็นแผนเดียว):

  1. เลขหน้าเริ่มติด prev ไล่ซ้าย→ขวาไปจนถึง next (ไม่ลอยกลาง)
  2. เลิกใช้ windowing แบบ "sibling รอบหน้าปัจจุบัน" (เดิม 1…3 4 5…7 ขยับตามหน้า) เปลี่ยนเป็นเรียงคงที่ 1 2 3 4 … N เสมอ ไม่ขึ้นกับหน้าปัจจุบัน

สิ่งที่แก้

  1. Pagination.jsx — เปลี่ยน pageList() จาก sibling-window เป็นเรียงคงที่: เลขหน้า 1..LEADING_COUNT (=4) เรียงต่อกัน ตามด้วย … แล้วปิดท้ายด้วยหน้าสุดท้ายเสมอ (ถ้า totalPages ≤ 5 โชว์ครบไม่ต้องมี …) ไม่รับ page เป็น argument อีกต่อไป — เซ็ตเลขคงที่ไม่ขึ้นกับหน้าปัจจุบัน (highlight หน้าปัจจุบันยังทำงานผ่าน p === page เดิม เฉพาะตอนหน้าปัจจุบันอยู่ในเซ็ตที่โชว์ — ข้อมูลจริง 121 คน/20 ต่อหน้า = 7 หน้า เข้าเซ็ตแสดงผลอยู่แล้ว (1-4, 7) มีแค่หน้า 5-6 ที่ตัวเลขไม่ highlight แต่ปุ่ม ‹/› ยังกดได้ปกติ — แจ้งไว้ ไม่ block)
  2. dashboard.css — .pagination ตัด justify-content: space-between, .pagination__pages เพิ่ม flex: 1 + เปลี่ยน justify-content: center → flex-start (เลขหน้าดูดพื้นที่ว่างทั้งหมดมาเป็นของตัวเอง แล้วชิดซ้าย — next ยังถูกดันไปชิดขอบขวาเหมือนเดิม)
// Pagination.jsx
const LEADING_COUNT = 4

function pageList(totalPages) {
  if (totalPages <= LEADING_COUNT + 1) {
    return Array.from({ length: totalPages }, (_, i) => i + 1)
  }
  const leading = Array.from({ length: LEADING_COUNT }, (_, i) => i + 1)
  return [...leading, ELLIPSIS, totalPages]
}
// call site: pageList(totalPages) — ตัด page ออกจาก signature
/* dashboard.css */
.pagination {
  display: flex;
  align-items: center;
  gap: 0.35rem;
  margin-top: 0.9rem;
}
.pagination__pages {
  display: flex;
  align-items: center;
  flex-wrap: wrap;
  justify-content: flex-start;
  gap: 0.35rem;
  flex: 1;
}

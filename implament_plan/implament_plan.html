Implementation Plan · Tooling / Workflow

Model-Switch Commands: /code (Opus) + /talk (Sonnet)

2026-07-07 · แผนก: ไม่เข้าแผนกไหน — เป็น tooling ส่วนตัวของ Gong (user-level ~/.claude/commands/) · ผู้เสนอ: วาฬ

?ทำไม (Why)

Gong ต้องการแยก model ตามงาน: coding → Opus ล่าสุด (effort high), คุย/อธิบาย → Sonnet ล่าสุด (effort high) เพื่อคุมคุณภาพงาน code และประหยัดโควตาเวลาคุยธรรมดา

ข้อจำกัดจริงที่ต้องรู้: Claude Code สลับ model อัตโนมัติกลางบทสนทนาไม่ได้ — กลไกที่มีจริงคือ (1) พิมพ์ /model เอง (2) slash command ที่ใส่ model: ใน frontmatter ซึ่งรันคำสั่งนั้นด้วย model ที่ระบุ. Gong เลือกแบบ 2 commands แล้ว (ตรงไปตรงมา ไม่มี noise)

1สิ่งที่จะสร้าง

CommandModelใช้เมื่อ
/code <งาน>opus (alias → ล่าสุดเสมอ)implement, fix, refactor, review code
/talk <คำถาม>sonnet (alias → ล่าสุดเสมอ)ถาม-ตอบ, วิเคราะห์, อธิบาย — ห้ามแก้ code

Effort: ไม่มี field ต่อ command — แต่ session default ของ Gong ตั้งเป็น high อยู่แล้ว (ตั้งผ่าน /effort เมื่อ 2026-07-07) ทั้งสอง command จึงรันที่ high อัตโนมัติ

2ไฟล์ที่แตะ

  • ~/.claude/commands/code.md — สร้างใหม่
  • ~/.claude/commands/talk.md — สร้างใหม่

เช็คแล้วไม่ชนชื่อเดิม (มีแค่ code-review.md) · ไม่แตะ /model-route (อันนั้นแค่แนะนำ model ไม่ได้สลับจริง) · ไม่แตะ repo trail-running เลย

--- code.md ---
description: Run a coding task on Opus (latest)
argument-hint: <coding task>
model: opus
---
# Code Mode — Opus
Task: $ARGUMENTS
(engineering rigor: explore ก่อนแก้, ตาม project rules, verify ก่อนจบ)

--- talk.md ---
description: Discussion / explanation on Sonnet (latest) — no code changes
argument-hint: <question or topic>
model: sonnet
---
# Talk Mode — Sonnet
Topic: $ARGUMENTS
(ตอบ/วิเคราะห์เท่านั้น ห้ามแก้ไฟล์ — ถ้ากลายเป็นงาน code ให้สั่งใหม่ผ่าน /code)

3วิธีตรวจ (Verification)

  1. เช็ค frontmatter ทั้งสองไฟล์ parse ถูก (สามขีดครบ, key ถูก)
  2. Gong เปิด session ใหม่ (commands โหลดตอนเริ่ม session) → พิมพ์ /code test → status line ต้องโชว์ Opus, /talk test → Sonnet
  3. จบคำสั่งแล้ว /model ต้องยังโชว์ default เดิมของ session

✗นอกขอบเขต

  • Hook ตรวจ keyword อัตโนมัติ — Gong ปัดตก (noise เยอะ)
  • Effort ต่อ command — Claude Code ไม่รองรับ
